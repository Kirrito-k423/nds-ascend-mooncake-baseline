# 预注册矩阵（MAC-16）

固定完整 Qwen2.5-72B dummy BF16、TP4、PD-colocated、graph、输出32、异步非layerwise加载。两节点版本和镜像相同。合成输入为固定种子 token ID，不与历史 AISBench chat 的1024/10结果直接比较绝对延迟。

| 实验 | 改变因素 | 固定条件 | 判定 |
|---|---|---|---|
| 计算/HCCL门禁 | 节点 | 四卡、64²矩阵/4096元素all_reduce | 精确匹配；20次均值只是门禁小样本 |
| native读回 | MEMORY/LOCAL_DISK、本机/远端 | 1/64MiB、同一非均匀字节、每轮重审计 | 三轮全量一致；SSD必须读前无MEMORY |
| 五档请求 | 前缀位置 | 每格同输入长度/并发/输出、同模型 | NPU缓存0、外部加载L−1；native返回字节为正 |
| 长度 | 1024/8192/16384/24576 | 同档/并发 | 不越25600配置；实际失败保留，未成功不称受支持 |
| 并发 | 1/8/25 | 同长度/档 | C×(L+32)≤实测token容量80%；否则标记未执行 |

每格3轮，每轮C个请求，共3C个样本。C1只有3个请求，不对P95/P99作强结论。冷目标节点用独立前缀校准；T1/T2要求源节点MEMORY-only。T3/T4单独启动SSD模式，等待完整LOCAL_DISK、租约过期后逐segment清除内存并重审计，防止回填污染。SSD恢复必须记录源盘读计数覆盖native实际返回字节、offload RPC计数增加。

默认只运行1024/C1五档校准。校准完成并复核后，用`NDS_CONFIGS_JSON`显式传入后续长度/并发，继续在同一顶层运行前台收集；不得把默认校准的`sampling_finished`解释为所有矩阵完成。

HBM与外部DRAM分开记账：HBM前缀通过显式reset构造未命中；DRAM仅源节点贡献4×100GiB，目标贡献0。SSD为eager持久化后租约清除，不能据此称自动压力换出已通过。累积前缀与活跃并发分别记录，当前每轮清理任务独占master，不操作共享池。

计时：客户端perf_counter_ns记录SSE；logprobs提供真实token数，要求单token事件才能输出精确间隔。native加载计时为每rank主机单调时钟，不能跨节点相减，不能把重叠加载相加为关键路径。磁盘/网卡计数窗口包含共享背景及计量结束后1秒异步保存，不能替代Host DRAM流量。UB链路计数若不可见需标缺口。

停止：数据错误、位置混合、加载不完整、没有真实盘读、服务异常或1800秒启动超时立即停该路径，保存失败。全局不清page cache，不改盘结构。没有可调用的SSD→HBM direct路径则不生成direct实测值。
