# 图 6：A5 单机 DeepSeek-V4-Flash + AgentX 轨迹回放

三级 KV 缓存（纯 HBM 5 GiB/卡 ／ +DRAM 11 GiB ／ +SSD 45 GiB 修复态）的命中率、服务侧 TTFT 与输入吞吐，横轴为设置 QPS。

- 图像：`figure6_15of15.png`
- 数据：`figure6_4panel_data.csv`（14 个已验收点 + 红侧 0.75 附条件观测）
- 红侧 0.75 批：窗内 224 条四类记录齐全、空内容 0、结构化 `-400` 0；15 条缺口全在窗外（窗尾截断）。该点实际发线 0.193 QPS，8 槽饱和，与红侧 0.50 档几乎同一工作点，不代表 0.75 QPS 的真实工作点。
- 命中率为响应声明值（缓存输入/输入 token），不是逐键物理 SSD 命中；各点机器不同（B06-1/2/3、B02-5），不构成严格配对。
